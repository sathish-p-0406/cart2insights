# Cart2Insights: Decoding E-Commerce Performance

An end-to-end analytics project on the Olist Brazilian e-commerce dataset: data cleaning, SQL storage, feature engineering, EDA, hypothesis testing and an interactive Streamlit dashboard.

## Objective
Turn 9 related raw tables (orders, customers, products, sellers, payments, reviews, geolocation) into business insights on sales, customers, sellers, delivery performance and customer satisfaction.

## Tech stack
Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn, Plotly, SQLAlchemy, SQLite (MySQL supported), Streamlit, Jupyter.

## Setup
1. Install Python 3.12 and create a virtual environment: `py -3.12 -m venv venv`, then activate it.
2. Install packages: `pip install -r requirements.txt`
3. Download the Olist dataset and place the 9 CSV files in `data/raw/`.
4. Run notebooks 03, 04 and 05 in order. They create `data/cleaned/` and the `cart2insights.db` database.
5. Launch the dashboard: `streamlit run streamlit/app.py`

**MySQL:** the code uses SQLAlchemy. Copy `.env.example` to `.env` and set `DATABASE_URL`. No credentials are stored in the code.

## Methodology
1. **Data quality:** missing values, duplicates, key uniqueness, invalid values and outliers (IQR rule).
2. **Cleaning:** date conversion, one review per order, one geolocation row per zip prefix, invalid payments removed, missing categories set to "unknown".
3. **SQL:** 9 tables with primary and foreign keys. Queries use joins, GROUP BY/HAVING, subqueries, CTEs and window functions.
4. **Feature engineering:** order value, delivery days, delivery delay, customer order count and spending, repeat-customer flag, seller revenue and order count.
5. **EDA:** univariate, bivariate, multivariate, trend, correlation and distribution analysis.
6. **Statistics:** Welch t-test, one-way ANOVA, chi-square test, each with assumption checks and effect sizes.
7. **Dashboard:** 6 interactive sections with state and period filters.

## Key findings
- **Delivery drives satisfaction:** delayed orders average 2.55 stars vs 4.30 for on-time orders (Welch t-test, p < 0.001, Cohen's d = 1.22). Orders never delivered average 1.74.
- **Retention is weak:** only about 3% of customers placed a second order.
- **Category affects spend:** average order value differs significantly across categories (ANOVA, p < 0.001, eta squared = 0.098). Computers average R$1,287 vs R$81 for electronics.
- **Payment method matters little:** the chi-square association is significant but negligible (Cramér's V = 0.028), except that voucher orders are canceled about 3x more often.
- **Geography:** São Paulo generates the most revenue by a wide margin (about R$5.8M in delivered orders), followed by RJ and MG.

## Recommendations
1. Improve logistics in slow states and set more realistic delivery estimates.
2. Launch retention campaigns (coupons, follow-up emails) for one-time buyers.
3. Promote high-value categories and bundle products in low-value ones.
4. Investigate the voucher checkout and fulfilment flow.

## Limitations
Observational data, so results show associations, not causes. Variances were unequal in the ANOVA, which was confirmed with non-parametric tests. The first and last months of the dataset are incomplete.
